# BVR COMMAND — 超视距空战指挥 v0.7.1

一个纯静态、零依赖的超视距（BVR）空战模拟/回放。界面仿 DCS F10 全局视图：浅色地图、白色细网格、品红 Bullseye、按机型绘制的俯视轮廓，标签为「FL 高度 + 马赫」。你坐在预警机上，指挥己方机群；不干预时飞机自主交战。

v0.2 的重点：**你也可能被击落** —— 预警机和加油机都是可被猎杀的目标，交战纵深因此拉长到 300 km 级；同时加入了备战编成、挂载、加油机、多机同时指挥和导弹实时可视化。

v0.3 的重点：**信息不再全知** —— 雷达接触按置信度分成「确认 / 模糊 / 记忆」三种画法，导弹发射后也不会立刻被对方看见；同时每款战机有了各自的气动外形轮廓、压制/主攻两种战术分工、更明显的垂直机动，选中飞机能看到它的雷达圈和数据链。

v0.5 的重点：**战术分工是动态的，规避是立体的** —— 飞机不再按空重固定职能，而是看手里还有没有远弹、有没有高度/速度优势：带远距弹的先打远弹（每目标最多两发），占高位的先开火，没优势的等进入不可逃逸区再打；被导弹锁定后会在 7 种机动里选一种（crank / notch / dive / extend / break / split-S / climb），水平与垂直同时变化，近距离优先硬拐和俯冲，远距离优先侧切消耗。导弹阻力也改成了按弹径估算的物理值，不再为了凑射程数字反推。

v0.6 的重点：**看得见的信息链路** —— 机载雷达分两种模式：LPI（低可截获，点线，静默扫描，被对方 RWR 察觉的距离只有 55%）和 STT（单目标跟踪，实线，连续照射，从更远处就会被对方察觉）。开火后到导引头开机之间，发射机用 STT 持续给导弹喂数据（橙色虚线）；导引头锁住目标后，弹和目标之间会画出一条末段锁定线。一架飞机可以同时维持多条链路（相控阵多目标）。图标里的三角形改成了白芯+本方颜色描边（DCS 风格），真实轮廓沿用 v0.5 的参数。

v0.7.1 的重点：**电子战与 A 射 B 导** —— 挂载里多了三种吊舱（宽频噪声 / DRFM 欺骗 / 随队自卫），开机后在地图上画出紫色干扰扇区，被覆盖的一方探测距离缩短、航迹质量下降、**数据链共享也会被削弱**、STT 照射有概率被打断、导引头被干扰时命中率下降；开干扰自己也会变得更显眼。导弹的中制导不再绑死在发射机上：任何能看见目标、且在数据链范围内的友机都可以接手照射（预警机也行），地图上用紫色虚线标「B导」，也可以手动指定。备战界面还能直接设定敌方战斗机数量。这一版同时修好了「备战界面打不开」和「三角形图标仍是实心」两个 bug。

## 运行

直接用浏览器打开 `index.html`（Chrome / Edge / Firefox 均可，无需服务器、无需构建）。

```
bvr-command/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ data.js     机型、挂载、导弹、想定数据
│  ├─ atmos.js    ISA 大气模型
│  ├─ sim.js      飞行动力学、导弹、探测、加油、战果
│  ├─ ai.js       自主决策（预警机 / 加油机 / 战斗机）
│  ├─ render.js   Canvas 地图渲染、机型轮廓、导弹尾迹
│  ├─ ui.js       备战界面、列表、指令面板、日志
│  └─ main.js     主循环与输入
├─ tools/build.js 打包成单文件版 / 绿色文件夹版
└─ test/
   ├─ smoke.js    数值与 15 分钟交战冒烟测试（Node）
   ├─ boot.js     DOM/Canvas 桩，跑主循环验证不抛异常（Node）
   └─ single.js   从单文件版抽回内联脚本再跑 boot
```

| 拖拽地图 | 平移 |
| 滚轮 | 缩放 |
| 右键点敌机 | 把当前选中编队的目标指为该机 |

| 1–5 | 1× / 2× / 4× / 8× / 16× 变速 |
| F | 显示全图（含未探测目标） |

右侧面板对**所有选中飞机**同时下达：高度滑杆（3000–18000 m，250 m 一档）、马赫滑杆（0.5–1.6）、指定/清除目标、航路点、自由/禁止开火、自主/规避/返航/加油；「同型全选」「全选战斗机」可批量。左侧「在空导弹」列出每枚弹的弹型、距离、TTI、阶段，点击可把视图移过去。

选中己方飞机时，地图上会画出它的**雷达探测圈与视场扇区**，并从预警机拉出到全队的**数据链虚线**；右侧详情面板同时给出雷达距离、视场角与数据链状态。

## 图标与锁定（v0.5）

- **两种图标**：右上角按钮或 `T` 键切换「真实轮廓 / 三角形」。真实轮廓是按参考三视图逐型画的俯视剪影：F-16 的 LEX、F-15 的宽机身与双垂尾、F/A-18 的大边条、MiG-31 的宽体大后掠翼、J-10 的鸭翼+三角翼、Flanker 家族（J-16 / J-11BG / Su-35S）、带鸭翼的 Su-30SM2；预警机是「机身 + 圆盘」，加油机是「机身 + 两根拖出的软管」，都不画发动机短舱。
- **火控照射线**：正在用火控雷达照住目标的战斗机，会向目标拉一条细虚线；选中该机时线会加亮。
- **导弹中制导**：己方导弹在飞行中时，从发射机到弹体有一条更淡的点线，表示还在中段指令修正。
- **数据链**：预警机到全队的绿色细虚线常显；选中飞机时该条加亮，并在飞机旁显示 `RDR …km · DL ON/OFF`。
- **被锁定告警**：被敌方火控雷达照射、且本机 RWR 能听到时，图标外会出现橙色虚线环 + 「被锁定」，详情面板显示「被锁定 ×N」。AESA 这类**低可截获**雷达的照射距离被压缩（`CONFIG.lpiFactor`），远距离照射可能完全听不到——这时地图上不会有任何提示，只有被打下来才知道。

## 电子战与 A 射 B 导（v0.7.1）

- **干扰扇区**：带吊舱的飞机开机后，地图上以本机为顶点画一片紫色半透明扇区（敌方的画成淡粉，且只有被你探测到才显示）。扇区就是它的作用范围。
- **干扰怎么算**：对每个被覆盖的传感器，按「干扰机功率 × 距离衰减」得到一个强度值；探测距离乘以 `1 − detect×强度`（有下限），航迹质量乘以 `1 − track×强度`。AESA 雷达有抗干扰折扣（`CONFIG.jam.eccm`）。所以被干扰时最直观的表现是：接触从「确认」掉成「模糊」，或者干脆丢目标。
- **数据链也被干扰**：预警机把航迹共享给全队时，接收端被压制的程度会再打一次折（`1 − 0.30×强度`，下限 0.65）。所以就算预警机自己没被干扰，只要队里的战斗机被压制，共享过来的航迹同样会掉档——压制得越狠，全队的态势越糊。
- **打断照射**：正在用 STT 制导的飞机若被 DRFM 覆盖，每 0.5 s 有一定概率被打断，退回 LPI；导弹随即失去中制导。
- **导引头被干扰**：目标自己开着吊舱时，末段命中率乘 `1 − 0.35×seeker` 的折扣。
- **开干扰的代价**：吊舱占 2 个挂点（少 2 发弹），并提高阻力和 RCS；开机的飞机在对方 RWR 上很显眼。
- **AI 何时开机**：被锁定、有来袭弹、或最近敌机进入 210 km 时自动开机；玩家可以在详情面板手动「干扰 开/关」或交回「自动」。
- **A 射 B 导**：导弹发射后，中制导由「谁能看见目标」决定，而不是必须发射机自己照射。优先级：玩家手动指定的制导机 → 发射机 → 离弹最近、且在 320 km 数据链内、对目标有 STT 航迹的友机（每机最多同时制导 4 枚）。换手时日志记一条「A 射 B 导：X 接手 Y 的弹」，地图上用紫色虚线标出，中点写「B导」。若没人能制导，导弹只能惯导漂移，命中率大幅下降。
- 在左侧「在空导弹」列表里，每枚弹会显示当前制导者（自身导引头 / 制导 XXX / B导 / 无制导）；选中己方飞机后点「B导」按钮，再点一架友机，就能手动把某枚弹交给它。

## 信息与置信度（v0.3 核心）

- **雷达接触分三档**：置信度 ≥75% 为「确认」——实心轮廓 + 机型 + 高度/马赫；35–75% 为「模糊」——虚线轮廓 + 误差圆 + 「?」标；更低的只留一个淡点（记忆航迹）。只有「确认」的接触才能被指定为目标。
- **置信度怎么来**：每个传感器按目标距离/雷达探测距离的比值给质量，越靠包线边缘越低；预警机的 360° 大雷达额外 +6%；没有传感器更新时每 0.5 s 衰减，75 s 后删除。
- **导弹不是发射即暴露**：自己打的弹永远可见；敌方导弹只有被本方预警机（40 km 内）或战斗机（18 km 内）雷达看到、或导引头开机被 RWR 感知后才显示。只收到告警、还没看见弹体时，目标机旁标橙色 `M!`，左侧列表记为「来袭告警 · 未捕获」。
- 这一层是为后续电子战留的接口：干扰、欺骗、数据链降级都只需改 `trackQuality` 与 `updateMissileVisibility`。

## 备战界面（开战前）

- 从机库挑选出战飞机，**总数上限 10 架**（含预警机和加油机）。
- 每架可选挂载：标准 / 纯超视距 / 轻载。挂载数量按真实正常空战收敛（重型机 8–12 枚、中型机 4–6 枚、J-10C 2–4 枚）；挂得越多，起飞重量越大、零升阻力越高、RCS 越大——轻载更灵活但弹少。
- 每架战斗机还能挂一个**电子战吊舱**（不占额外编制，但占 2 个挂点、少 2 发弹，并增加阻力与 RCS）：
  - 宽频噪声：250 km 覆盖、扇区 60°，探测距离压到 40%–100%，自己也最显眼；
  - DRFM 欺骗：180 km 覆盖、扇区 69°，主要打航迹质量与 STT 照射（更容易让对手丢失锁定）；
  - 随队自卫：90 km 全向、功率小，主要保护自己和身边的友机。
- **敌方战斗机数量**用滑杆设定（0–10），或勾选「随机」在 2–10 之间抽；只影响战斗机，敌方预警机/加油机各固定 1 架。默认值取当前想定原来的编成。
- 顶部统计参战飞机、总挂弹数与阻力惩罚；选好点「开始交战」。
- 已出战的编成会被记住，「再来一局」沿用同一套编成。

## 模型要点

- **大气**：ISA 分层（对流层 −6.5 K/km，11–20 km 等温，20–32 km 回升），密度由理想气体状态方程给出，声速 `a = sqrt(1.4RT)`。
- **飞行**：升力限制过载（`clmax·q·S/(m·g)`）与结构过载取小；诱导阻力 `Cd = cd0 + 0.05·CL²`；推力随密度 `(ρ/1.225)^0.7` 衰减；爬升消耗动能（`dv = (T−D)/m − g·(dh/dt)/v`）；燃油消耗与失速下沉。
- **挂载**：`mass += Σ弹重`，`cd0 ×= 1 + 0.028n`，`rcs ×= 1 + 0.018n`（n 为挂弹数）。
- **导弹**：固体火箭推力 + 气动阻力、远距 loft 至 24 km、比例导引（`a = 3.6·Vc·λ̇`，Vc 有下限防止侧切时发散）、末段能量修正（速度越低 Pk 越低）、3/9 线 notch 与 chaff 修正、1 km 引信半径。七种弹的 `CdA` 按弹径估物理值（0.0048–0.029 m²），推力再反向校准到公开射程（AIM-120D 180 km、PL-15 200 km、R-77-1 110 km、R-37M 300 km、AIM-9X 25 km、PL-10 25 km、R-73 20 km）；燃尽后速度掉到 220 m/s 即自毁，避免「目标迎头撞上滑翔死弹」凑出假射程。
- **探测**：本机雷达（战斗机 60° 视场，预警机 180°），探测距离随 RCS 的 0.25 次方缩放；预警机通过数据链共享给全队；航迹按置信度衰减（见上）。
- **战术分工**：不再按空重固定。每次选目标时重算：手里还有 ≥150 km 的弹、且对该目标还没打过 2 发远弹 → **远距压制**（0.45/0.38 包线开火，打完 7 s 侧转 crank）；否则比高度，高 2500 m 以上 → **高位主攻**（包线 +0.16/+0.10/+0.04）；都没有 → **主攻**（0.40/0.32，等接近率 ≥100 m/s 才打）。目标在跑（closing<0）时包线 ×0.55。玩家可在详情面板看到当前角色。
- **垂直机动**：AI 按距离分档选高度（11.5 / 10.6 / 9.6 / 8.4 / 7 km），并与目标保持 3500 m 以内的高差；防御时在 7 种机动里按距离随机选一种，水平转向与高度变化同时发生（crank 侧切、notch 3/9 线、dive 俯冲、extend 拖带、break 硬拐、split-S 半滚倒转、climb 爬升），每段保持 4–8 s。
- **加油**：战斗机初始 62% 内油，低于 18% 会自主找加油机（或玩家下令「加油」）；进入 8 km / 1200 m 内自动对接，按加油机速率输油，加满 90% 自动解除。
- **AI**：预警机 / 加油机按威胁圈后撤、遇袭掉头；战斗机优先级 油量红线 > 规避（含还手）> 加油 > 返航/无弹 > 航路点 > 选目标 > 接近开火；防御时走 3/9 线、俯冲、放 chaff。
- **轮廓**：15 种机型各自的俯视剪影（主翼后掠/根梢弦、平尾、鸭翼、单/双垂尾、圆盘、软管），由 `data.js` 的 `SHAPES` 参数驱动，渲染时按指令数组缓存；`T` 键可切回三角形图标。
- **锁定**：`sim.updateLocks` 每 0.5 s 统计谁在照谁；被照射方能否收到 RWR 告警取决于距离与对方雷达是否低可截获。中制导与 A 射 B 导的换手也在这一步完成（写 `guiderId`）。
- **电子战**：干扰强度 = 功率 ×（0.35 + 0.65 × 距离衰减），AESA 抗干扰 ×0.55；探测距离、航迹质量、STT 中断概率、末段 Pk 分别按吊舱的 `detect / track / stt / seeker` 缩放。

## 想定

- `us_cn`：USAF（2×F-15EX / 4×F-16C / 2×F/A-18E + E-3G + KC-135R）vs PLAAF（3×J-16 / 2×J-10C + KJ-500 + HY-6）
- `us_ru`：USAF vs VKS（3×Su-35S / 2×MiG-31BM / 1×Su-30SM2 + A-50U + Il-78M）
- `cn_ru`：PLAAF vs VKS

战斗机初始相距约 300 km，预警机在后方约 100 km；也就是说，要打到对方预警机，必须先穿透或绕过战斗机屏障。

胜负判定（按顺序）：一方飞机全灭 → 清场；一方**战斗机**全灭且空中无弹 → 击溃战斗机群；双方战斗机都没弹且 90 s 无发射 → 弹药耗尽；240 s 无发射且空中无弹 → 脱离接触；30 分钟 → 超时按存活数与战果判定。

`dist\` 里有三种形态：

## 说明

参数取自公开资料（厂商手册、公开射程数据、公开 RCS 估计），用于教学/娱乐级模拟，不是工程级性能模型；隐身机、地形遮蔽、地空导弹均未建模；电子战只做到「干扰扇区影响探测/跟踪/制导」这一层，没有做频段匹配与抗干扰算法。

平衡性：三个想定不完全对称（PL-15 的射程优势是真实存在的），`us_cn` 对蓝方最有挑战，`cn_ru` 蓝方（中国）优势明显。用备战界面调整编成和挂载是最直接的难度旋钮。
